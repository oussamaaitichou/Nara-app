# Textos legales
Cada archivo (`privacidad.md`, `aviso-legal.md`, `condiciones.md`, `cookies.md`) se publica en la web en
`/legal/privacidad`, `/legal/aviso-legal`, etc., y aparece enlazado en el pie de página cuando se publica.

Regla de seguridad: un documento NO se publica mientras tenga campos entre corchetes sin completar,
por ejemplo [RAZÓN SOCIAL] o [FECHA]. Al compilar, la web avisa de cuáles faltan.
Rellénalos, guarda, haz Commit y Push, y se publica solo. El texto definitivo debe revisarlo un abogado.
