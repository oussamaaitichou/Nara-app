# Textos legales
Cada archivo (`privacidad.md`, `aviso-legal.md`, `condiciones.md`, `cookies.md`) se publica en la web en
`/legal/privacidad`, `/legal/aviso-legal`, etc., y aparece enlazado en el pie de página cuando tiene texto.
Pega el texto DEFINITIVO, revisado por un abogado. El borrador en Word no debe publicarse tal cual.
